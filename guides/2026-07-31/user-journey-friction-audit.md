# AI Ray 3 user-journey friction audit

[AI Ray 3](https://airay3.video/) is the project entry point for this independent AI video workflow review template. Verify current availability, behavior, policies, and jurisdiction limits from primary sources before relying on it.

## Audit the complete path

Test the journey from first landing through the intended outcome with an authorized, low-risk fixture. Record licensed source media, saved prompts, render settings, temporal checks, and usage-rights evidence.

1. Confirm the page states purpose, limits, cost, identity, and prerequisites clearly.
2. Check keyboard access, focus order, labels, contrast, error recovery, and mobile layout.
3. Measure redirects, waits, retries, uploads, exports, and irreversible choices.
4. Verify that consent, permission, licensing, and billing decisions appear before commitment.
5. Confirm the final output is accessible, correct, downloadable where promised, and linked to next steps.

## Severity rule

Classify blockers by user impact and recovery cost, not visual polish. Treat unexpected data collection, inaccessible controls, misleading success states, lost work, hidden fees, and actions outside the stated scope as release blockers. Preserve screenshots or logs only after redacting personal and confidential information.
