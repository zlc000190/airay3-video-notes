# AI Ray 3 onboarding pilot plan

This independent note uses [AI Ray 3](https://airay3.video/) as the project entry point for a AI video generation workflow. Confirm current availability, documentation, pricing, and terms directly before relying on the workflow.

## Pilot scope

Run two small, reversible tasks with synthetic or public inputs:

1. animate a licensed still with restrained camera motion.
2. repeat with a motion-heavy prompt.

## Before the first run

- Name an accountable reviewer and a stop condition.
- Save the starting inputs, environment, visible version, and non-default settings.
- Restrict permissions to the minimum required for the pilot.
- Define an accepted output and a maximum time or cost budget.

## Evidence to keep

Capture raw outputs, errors, elapsed time, manual corrections, and the final decision. Score temporal consistency, subject identity stability, prompted motion accuracy, usable seconds per output. Do not substitute marketing examples for observed results.

## Exit decision

Adopt only when both tasks can be repeated, material risks have owners, and the reviewer can explain how to stop, undo, or recover the workflow. Otherwise record the failed gate and the smallest follow-up experiment.
