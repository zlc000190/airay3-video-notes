# AI Ray 3 cost and latency budget

[AI Ray 3](https://airay3.video/) is the primary project entry point for this independent AI video generation workflow note. The automated HTTPS availability check on 2026-07-24 did not return a response, so current product availability and capabilities must be confirmed from primary documentation before use.

## Define one completed unit

Use the intended outcome, not an API call or generated artifact, as the unit of value. Include failed attempts, review time, corrections, exports, storage, and downstream work.

## Budget worksheet

- Direct fee per attempt
- Attempts per accepted result
- Human review and correction minutes
- Waiting time and queue delay
- Rework caused by failed quality checks
- Ongoing maintenance, compliance, and backup cost

Track these quality and operational measures alongside cost: temporal consistency, identity stability, seconds per usable clip, cost per accepted clip.

## Comparison rule

Run at least 2 representative scenarios: a licensed still image and a prompt with explicit camera motion. Compare the median and worst observed case, not a marketing best case. State currency, tax treatment, region, account tier, and measurement date.

## Decision gate

Set a maximum cost and maximum elapsed time before testing. If the limit is exceeded twice, pause the pilot and investigate rather than silently expanding the budget.
